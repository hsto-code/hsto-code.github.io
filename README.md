## Veröffentlichung mit dem iPhone

1. ZIP in der Dateien-App speichern und antippen, um sie zu entpacken.
2. Safari öffnen, https://github.com aufrufen und als hsto-code anmelden. Die folgenden Schritte sind für den Browser gedacht.
3. https://github.com/new öffnen. Repository-Name: hsto-code.github.io. Public auswählen, Add README aktivieren und Create repository wählen. Falls dieses Repository bereits existiert, verwenden und vorhandene Inhalte vor dem Ersetzen prüfen.
4. Im Repository unter Code: Add file → Upload files → choose your files. Über Dateien auswählen in den entpackten Ordner gehen und index.html, icon.svg, qr.png sowie stephane-tolale.vcf auswählen. Falls die Auswahl nur ein Element zulässt, nacheinander hochladen. Optional auch .nojekyll und README.md hochladen; die Dateien-App blendet .nojekyll möglicherweise aus.
5. Commit changes wählen und die Änderungen auf main speichern. Die ZIP selbst nicht hochladen. index.html muss direkt auf der obersten Ebene liegen.
6. Settings → Pages → Build and deployment → Source: Deploy from a branch. Branch: main. Ordner: / (root). Save wählen.
7. Bis zu zehn Minuten warten. Danach https://hsto-code.github.io/ öffnen. In Settings → Pages steht auch Visit site.
8. Wenn Menüs fehlen, in Safari über das Seitenmenü Desktop-Website anfordern und gegebenenfalls das Querformat verwenden.

## Prüfen

- Deutsch und Englisch umschalten.
- Kontakt speichern öffnen und den Kontaktimport prüfen.
- Kontakt aufnehmen öffnet eine E-Mail an stephane.tolale@outlook.de.
- LinkedIn öffnet das Profil.
- Karte teilen öffnet das Teilen-Menü oder kopiert die Seitenadresse.
- QR-Code mit einem zweiten Gerät scannen.

QR-Code und Teilen-Funktion verweisen bereits auf https://hsto-code.github.io/. Die Veröffentlichung erfolgt erst nach den obigen Schritten. Besucher benötigen kein GitHub-Konto.
